# 한컷영단어 발음연상 연구 v3 — 소리 고리 우선

## 실제 한국어·상용 외래어 탐색
- 영어 IPA와 강세에서 발음 고리를 탐색한다. 단어 뜻만 풀어쓴 문장은 연상법이 아니다.
- 실제 사용되는 한국어 단어, 일반적인 외래어, 자연스러운 일상 대사를 활용한다. 가짜 단어·맥락 없는 감탄사 금지.
- 뜻을 실제 행동으로 보여주는 한 장면을 만들고 해당 한국어 고리를 대사에 넣는다.
- 음절이 조금만 유사하면 부분 유사라고 명시한다. 발음이 완벽히 일치한다고 과장하지 않는다.
- 강세·IPA·품사를 별도 검증하고, 이미지 생성 전 사람의 최종 공개 승인 유지.

## 긍정 기준 사례: conceal
영어: conceal /kənˈsiːl/ / 감추다·숨기다.
연상 고리: 컨실러(실제 쓰이는 화장품 이름, 잡티를 가리는 용도).
연상 대사: “컨실러로 잡티를 싹 숨겼어!”
장면: 거울 앞 인물이 얼굴 잡티를 컨실러로 가리며 친구에게 자연스럽게 말하는 한 컷.
주의: 외래어에서 유래된 연상임을 표시, 실제 영어 발음과의 차이를 평가할 것. 다른 단어에 획일 적용 금지.

## 탈락 기준 사례
- conceal: “가방 안에 몰래 숨겼어”, “책 뒤에 숨겼어”, “비밀을 잘 숨겼네” → 뜻만 묘사하고 소리 고리 없음.
- abandon: “네가 밴 돈이잖아! 돌려줘!” → 음성 일부만 닮고 버리다/포기하다 뜻 연결 없음.

## 운영 프로세스
3안 생성 → 발음 고리·뜻 직접성 독립 검수 → 최적안만 이미지 생성 → 검수 대기.
통과자가 없으면 비용을 쓰며 이미지 생성하지 않는다. 자동 공개 금지.
