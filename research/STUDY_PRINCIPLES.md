# 영상 분석을 이용한 한컷영단어 콘텐츠 설계

기준 자료: 사용자가 제공한 약 56분 길이의 `수능 영단어 100단어 1시간 암기하기!.mp4` 및 기존 100항목 색인. 색인의 뜻은 참고 풀이이며 영상의 축자 자막 전사가 아닙니다. CSV 100행은 분석용 참고 목록이고, 해당 영상의 특정 대사/그림을 재현하거나 사용한 학습 데이터가 아닙니다.

## 실무 원칙
1. 발음: IPA를 기준으로 강세 음절을 확인. 자연스러운 한국어 발화와 소리 연결이 약하면 고득점 금지.
2. 한국어: 한국인이 실제 말할 수 있는 표현이어야 함. 억지 분절·발음 왜곡·문자 단위 말장난은 보류.
3. 의미: 한 컷의 명확한 행동이 단어 뜻을 직접 보여야 함. 뜻이 반대거나 연관만 있을 때 보류.
4. 그림: 핵심 소리 고리를 유발하는 대사를 필요한 경우 그림 안 말풍선으로 표현. 영단어/IPA/뜻은 카드 텍스트로 분리.
5. 스코어: 30(소리),25(자연스러움),25(뜻 연결),20(장면) 합계 100. 독립 평가 재점검 후 85+, 소리24+, 자연19+, 뜻20+ 통과 시 자동 이미지 제작, 그 외는 보류.
6. 단계: 자동 초안 생성 → 검수 전 이미지 → 관리자 최종 공개. 영상의 학습 구성 10개 묶음/즉시 복습/퀴즈는 학생용 학습 흐름에만 참조.
7. 각 100항목을 실증 학습 데이터로 과장하지 말 것. 실제 성공률·암기 효과는 학생 테스트가 필요함.
