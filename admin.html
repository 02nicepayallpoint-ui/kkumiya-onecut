v5.3.0 · ZIP 한 번에 등록
현재 제작 흐름 · ChatGPT에서 확정한 텍스트와 이미지를 패키지로 받아 ZIP 한 번에 등록 → 검수 → 공개합니다. ZIP 안에는 콘텐츠 엑셀 1개 + 영어단어_핵심뜻.png 형식 이미지(예: urgent_긴급한.png)가 있으면 됩니다. AI 이미지 생성·AI QA는 다시 실행하지 않으며 자동 공개도 하지 않습니다.
엑셀 행 순서, 이미지 파일명의 영어 단어 또는 001_ 앞번호로 자동 매칭합니다. 신규 카드는 비공개 초안으로 저장됩니다.

엑셀로 AI 웹툰 제작

한컷영단어 엑셀(.xlsx)의 연상·말풍선·이미지 장면을 그대로 가져옵니다. 뜻마다 독립 카드로 등록하며 기존 공개 카드는 수정하지 않습니다.

v5.3.0 · 검증 이미지 일괄등록
엑셀을 선택하면 17개 콘텐츠의 유효성·중복 여부를 먼저 검사합니다.

엑셀의 확정 연상문장·장면을 그대로 사용합니다. 처음에는 1장 시험을 권장하고, 확인 후 ‘남은 전체 이미지 자동생성’으로 이미지 없는 카드만 순서대로 제작할 수 있습니다. QA 실패·API 오류는 자동 재시도하지 않으며 자동 공개도 하지 않습니다.

검증 완료 이미지 일괄 등록

이 채팅에서 먼저 검수한 이미지를 ZIP으로 한 번에 등록합니다. 이미지 파일명은 영어단어_핵심뜻.png 형식(예: urgent_긴급한.png)으로 저장해 주세요. 기존 001_단어.png, 002_단어.png … 순번도 지원합니다. AI 이미지 생성·AI QA를 다시 실행하지 않으며 자동 공개도 하지 않습니다.

파일명의 영어 단어 또는 엑셀 순번으로 자동 매칭합니다. 일부 이미지만 올릴 때도 단어명(예: urgent_긴급한.png)이나 원래 순번(예: 006_)을 유지하세요.
