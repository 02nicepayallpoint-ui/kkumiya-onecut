# 한컷영단어 v5.3.0

AI 발음연상 영단어 학습앱 통합본입니다.

## 핵심 흐름
- ChatGPT에서 뜻별 발음연상 콘텐츠 + 강세 표시 엑셀 제작
- 관리자에서 엑셀 등록 → AI 웹툰 이미지 제작 → 이미지 QA → 관리자 공개
- 학생 화면에서 단어·IPA·뜻·웹툰·예문·학습기록 제공

## v5.2.5 핵심 변경
- 강세를 코드가 추측하지 않고 엑셀 `강세 표시` 열에서 읽습니다.
- 표기 예: `con[tam]inate`, `contami[na]tion`, `[core]`
- 대괄호 안 철자만 학생 화면에서 빨간색으로 표시합니다.
- 강세 데이터가 없거나 형식이 틀린 신규 엑셀 행은 등록 전에 오류로 표시합니다.

## 실행
`python server.py`

- 학생: http://localhost:8766/
- 관리자: http://localhost:8766/admin.html
